# TIMER
소진공 AI

브라우저에서 바로 여는 포모도로 타이머입니다. `index.html` 파일 하나에 HTML·CSS·JS가 모두 들어 있습니다.

## 기능
- 집중 25분 / 짧은 휴식 5분 / 긴 휴식 15분(집중 4회마다) 자동 전환
- 시작·일시정지·리셋·건너뛰기, 원형 진행 표시, 오늘 완료 횟수
- 종료 알림음(Web Audio), 탭 제목에 남은 시간 표시
- 시간 설정 변경(브라우저에 저장), 다크 모드, 휴대폰 화면 지원
- 단축키: Space 시작/일시정지 · R 리셋 · S 건너뛰기

## 사용법
`index.html`을 내려받아 브라우저로 열면 됩니다.
